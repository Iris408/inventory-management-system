# PartsPilot Power BI

This directory contains documentation and supporting assets for the PartsPilot Power BI reporting dashboard.

## Current Status

The Power BI dashboard is connected to PartsPilot inventory data and is being developed as the analytics layer for the wider inventory platform.

## Current Visuals

- Total inventory value
- Total stock quantity
- Inventory by category
- Stock by status
- Inventory value by category
- Inventory status distribution

## Planned Improvements

- Low-stock products table
- Top products by inventory value
- Supplier analysis
- Automotive-specific category data
- Additional operational KPIs
